## Evidence Structure

**Pre-tool-call reasoning block {{pre_reasoning_part_id}}:**
Contains the model's thinking before the tool call. Review this to understand:
- Why the model selected this tool (as opposed to other available tools)
- How the model prepared the tool call parameters
- What assumptions or information guided the decision

**Tool call and result block {{tool_call_part_id}}:**
The actual tool call (showing parameters) and the result/output returned by the tool.
Review this to assess:
- Whether parameters match the tool's expected signature
- Whether the result data is what was requested
- Any errors, malformed responses, or empty results

**Post-tool-call reasoning block {{post_reasoning_part_id}}:**
Contains the model's reflection on the tool result. Review this to understand:
- Whether the model was able to use the result to make progress
- If expectations were met or if issues arose
- How the model integrated the result into the next step

**Tool descriptions context:**
The tool definitions that were available to the model during the call decision.
Use these to assess whether the model correctly understood the tool's purpose and parameters.
If an error has occured, check the tool call against the documentated parameters and include any findings in the diagnostic.
